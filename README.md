# EMOM – skarbnica treningów

Timer EMOM z biblioteką ćwiczeń kettlebell, kreatorem własnych setów i dziennikiem treningów.
Jeden plik `emom_timer.html` – działa offline, także otwarty z dysku telefonu.

- Aplikacja online: https://tomshowgis.github.io/emom/emom_timer.html
- `yt_embed.html` – strona pośrednia dla playera YouTube, gdy aplikacja jest otwarta z pliku (YouTube wymaga nagłówka Referer).

Źródła treningów: Vadim Kettlebell, FitDad, Kingdom Kettlebells (linki w aplikacji).
